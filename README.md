# WatchNest
- A Movie tracking website where users can discover Popular , Upcoming  and top rated moves also they can filter Genre and search for specific movies.

## Live Demo 

**Live Webiste ->**[Watchnest](https://udayprakash999.github.io/WatchNest/)

## Features

- Interactive Navigation
- Responsive Layout
- Movie Search
- Popular Movies
- Upcoming Releases
- Genre Filtering 
- Movie Rating (View Ratings For each movie)
- Dynamic Movie Cards
- Movie Overview
- Dark Theme

## Tech Stak

- HTML5
- CSS3
- javaScript
- TMDB API
- Google fonts

- Dynamically creating and updating Html elem
- fetching data from third party REST API
- Implmenting movie search
